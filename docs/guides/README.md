# Feature guides

One short guide per feature. Each says what the feature is for, the steps, and how to
check it worked. They assume you have done the Quick start in the
[project README](../../README.md) (tools installed, `showcase setup` run once).

Every setting mentioned here is listed in one place in
[A video from a config](../config-driven-video.md).

| # | Guide | Use it when you want to |
|---|---|---|
| 1 | [Start from a config](01-start-from-a-config.md) | Describe a video in a file and render it |
| 2 | [Set the length](02-length.md) | Make a 30, 60, 90 or 180 second video, or any length |
| 3 | [Platforms and shapes](03-platforms-and-shapes.md) | Make videos for YouTube, Shorts, Reels, TikTok, LinkedIn and others |
| 4 | [Your own script](04-your-own-script.md) | Use narration you wrote yourself |
| 5 | [Fonts, colours and captions](05-style.md) | Match the video to your brand |
| 6 | [The rounded border](06-rounded-border.md) | Change or turn off the border and backdrop |
| 7 | [Motion scenes](07-motion-scenes.md) | Make an opening, a "how it works" card or an ending |
| 8 | [Sound effects](08-sound-effects.md) | Choose click and highlight sounds that suit the product |
| 9 | [A hosted product](09-hosted-product.md) | Film a live product safely, with a sign-in |
| 10 | [Explore the product](10-explore.md) | Get a map of screens and selectors before writing scenes |
| 11 | [With Claude Code](11-with-claude-code.md) | Let an agent write the script and scenes |
| 12 | [Node and npm](12-node-and-npm.md) | Run the kit without Bun, or build the package |

All examples use the `showcase` command. In the kit's own folder, write
`bun run showcase` in its place.
